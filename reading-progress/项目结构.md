> 生成日期：2026-09-24

## 怎么用这份文件

下面 ```xmind 代码块里的内容是**缩进式大纲**：

1. **导入 XMind**：XMind → 文件 → 导入 → Markdown，选中本文件即可；或把代码块内容复制出来单独存成 `.md` 再导入。
2. **直接阅读**：每级缩进就是一层主题，`—` 后面是该节点的作用说明。
3. **查找**：在编辑器里搜章节号（如 `实验 6-3`）或目录名。

> **取舍说明**：11,256 个文件不可能逐个列，也不该逐个列。这里的粒度是——
> 每个**目录**都有；每个**实验**都有（含入口脚本）；根目录与构建链的**每个文件**都有；
> 重复文件归纳成一行（如「12 份多语言 README」「132 张配图」）。

## 几条容易踩的认知偏差

1. **多语言 README 只在章级**：`chapterN/README.{12 语言}.md` 存在，但**实验目录里只有一份 `README.md`**（中英混排，用 `[English](#english)` 锚点分隔）。

2. **实验编号会漂移**：多章经历过重编号，**运行目录名保留历史编号**。例如 chapter2 的 `attention_visualization/runs/` 下同时有 `exp2-2-*` 和 `exp2-7-*`；chapter5 全表从 5-1~5-14 挪到 5-3~5-16。查编号以**各章 `EXPERIMENT_LEDGER.md` 为准**，它是唯一记录「当前编号 ↔ 归档编号」对照的地方。

3. **`results/` 被全局 gitignore**：chapter7 台账里引用的部分结果文件在本地工作树中并不存在（只白名单放行了少数几个）。不是你的仓库有问题。

4. **有些实验只有 README**：chapter8 的 `AdaptThink`、`SimpleVLA-RL`、`SpatialReasoning`、`AWorld-train`、`RLVP`、`retool` 是**复现指南**（📖），上游源码需按 README 里的固定 commit 自行 clone。chapter6 的 `claude-computer-use-native` 同理。

5. **体积大头是证据不是依赖**：仓库里没有 `node_modules`、没有预训练权重、没有虚拟环境。占地方的是验收产物——chapter8 的 1024 个机器人 rollout 录像（52 MB）、chapter10 `generative-agents` 的仿真状态快照（87 MB）、chapter5 的幻灯片截图与视频抽帧（230 MB）。

6. **`cursor-chats/` 不是产物**：只是被一并存档的写作过程对话，269 个文件不参与任何构建。
